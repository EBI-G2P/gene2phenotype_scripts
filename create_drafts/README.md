# Create Drafts

Scripts for creating automatic G2P draft records from ClinGen, Immuno, or in-house data.

## ClinGen Workflow

Run the ClinGen scripts in this order:

1. `fetch_clingen.py`
2. `gemini_analise_clingen.py`
3. `create_draft_records.py`

`create_draft_records.py` expects the Gemini-enriched JSON from `gemini_analise_clingen.py`. The JSON generated directly by `fetch_clingen.py` is not sufficient for draft creation because it does not contain the Gemini-extracted publications, mechanism, allelic requirement, phenotypes, and mechanism evidence.

## `fetch_clingen.py`

Extracts ClinGen evidence summaries and experimental evidence from the ClinGen gene-disease validity download.

Options:

- `--input_file`: ClinGen gene-disease validity CSV. Download from https://search.clinicalgenome.org/kb/downloads#section_gene-disease-validity, section "Gene-Disease Validity Curations".
- `--output_file`: Optional output JSON file. Defaults to `clingen_extracted_data_YYYY-MM-DD.json`.

Example:

```bash
python fetch_clingen.py \
    --input_file Clingen-Gene-Disease-Summary-2025-11-11.csv
```

## `gemini_analise_clingen.py`

Uses Gemini to extract draft-record fields from the ClinGen evidence summaries.

The input file is read-only. The script writes analysed records to the output file. If the output file already exists, records already present in that file are skipped so interrupted runs can be resumed.

Options:

- `--config`: Config file containing Gemini model details.
- `--input_file`: Input JSON file generated by `fetch_clingen.py`.
- `--output_file`: Optional output JSON file. Defaults to `<input_stem>_gemini.json`.
- `-l`, `--limit`: Optional number of records to process.
- `--clingen_panel`: Optional ClinGen panel filter. Defaults to all panels.

Config format:

```ini
[project_config]
key_file = <Google Vertex AI key JSON>
model = <Gemini model, default gemini-2.5-flash>
location = <Gemini model location, default europe-west2>
project = <Google Cloud project>
```

Example:

```bash
python gemini_analise_clingen.py \
    --input_file clingen_extracted_data_2026-09-25.json \
    --output_file clingen_extracted_data_2026-09-25_gemini.json \
    --config config.ini \
    --clingen_panel "Hearing Loss Gene Curation Expert Panel"
```

## `create_draft_records.py`

Creates automatic draft records in G2P.

Supported sources:

- `clingen`: creates drafts from Gemini-enriched ClinGen JSON.
- `immuno`: creates drafts from an immunology workbook plus Gemini-enriched ClinGen JSON.
- `inhouse`: creates drafts from an in-house mined-publication CSV.

Options:

- `--source`: Required. One of `clingen`, `immuno`, or `inhouse`.
- `--input_file`: Required. ClinGen JSON for `clingen` and `immuno`, or in-house CSV for `inhouse`.
- `--config`: Required. Config file with G2P API details.
- `--panel`: Required. G2P panel name, for example `"Ear disorders"`.
- `--clingen_panel`: Optional ClinGen panel filter when `--source clingen`.
- `--immuno_file`: Required when `--source immuno`. Immunology workbook in xlsx format.
- `--genes_to_include`: Optional gene-symbol allowlist, one gene per line.
- `--output_file`: Optional JSON output file. If set, drafts are written to this file instead of inserted into the API.

Example ClinGen usage:

```bash
python create_draft_records.py \
    --config config.ini \
    --source clingen \
    --panel "Ear disorders" \
    --clingen_panel "Hearing Loss Gene Curation Expert Panel" \
    --input_file clingen_extracted_data_2026-09-25_gemini.json
```

Example Immuno usage:

```bash
python create_draft_records.py \
    --config config.ini \
    --source immuno \
    --panel "Immunological disorders" \
    --input_file clingen_extracted_data_2026-09-25_gemini.json \
    --immuno_file immuno_panel.xlsx
```

Example in-house usage:

```bash
python create_draft_records.py \
    --config config.ini \
    --source inhouse \
    --panel "Cardiac disorders" \
    --input_file mined_publications.csv
```

Use `--output_file` to inspect generated draft payloads before inserting them:

```bash
python create_draft_records.py \
    --config config.ini \
    --source clingen \
    --panel "Ear disorders" \
    --input_file clingen_extracted_data_2026-09-25_gemini.json \
    --output_file clingen_drafts_to_review.json
```
